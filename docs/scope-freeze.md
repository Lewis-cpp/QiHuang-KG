# 首版范围冻结

冻结日期：2026-10-04。以本次任务和既有开发计划为依据，新增功能单独调整范围，不自动进入当前阶段。

## 产品与技术边界

产品面向中医药学习和文献资料检索。首版目标是检索、详情、来源证据、局部图谱、自然语言条件解析和带引用的方剂解释。数据仅接入本草典核心数据与 TCM-MKG D1～D7，同名实体不跨类型或来源自动合并。

| 项目 | 冻结选择 |
| --- | --- |
| 前端 | Vue 3 + TypeScript + Vite；后续局部图谱再接入 Cytoscape.js |
| 后端 | Python 3.12 + FastAPI 单体；无需第二套 Java 后端 |
| 当前主库 | PostgreSQL 18.6；Vastbase 迁移在最终交付前完成并重新验收 |
| NoSQL | Neo4j 5.26 社区版；同批次关系库数据生成图投影 |
| 模型 | 服务端 OpenAI 兼容 Chat Completions；按用户安排暂留空，后续自行接入 |
| 数据口径 | 去重实体 + 业务关系不少于 100,000；当前为 199,876 |
| 维护与账户 | 离线发布；无 Web CRUD 要求时不建设管理后台或多角色账户 |
| 交付日期 | 尚未提供，沿用相对周次，不设虚构截止日期 |

首版不包含个体诊疗、处方推荐、OCR、六源全量融合、自动跨来源合并、复杂图推理、向量数据库、通用多轮聊天或移动端。P1 的配伍提示、共现统计和朝代筛选不进入当前阶段。

## 本阶段交付边界

| 工作 | 当前阶段 | 后续功能 |
| --- | --- | --- |
| PostgreSQL | 真实版本、批次、参数化查询、事务、约束、索引与数据统计 | Vastbase 迁移及最终性能验收 |
| Neo4j | 实例、约束、索引、持久化样例、一至两跳查询与回滚 | 全量投影、图交互、完整备份恢复演练 |
| 模型 | 配置模板、调用脚本与自行接入说明；真实调用按用户安排延期 | 连接验证、完整 AI API、提示评测和内容审查 |

| 前端 | 真实统计、检索、连接状态与关系样例页面 | 完整详情、图谱画布与 AI 界面 |

后续模型验证最多两次请求，每次默认最大输出 1,024 token、超时 30 秒，无自动重试。实际模型名和用量来自真实响应；配置缺失时健康状态为 `not_configured`，显式验证为 `blocked`，不能标记连接已通过。刷新健康状态不产生模型请求。

## 验收规则

1. Vue 通过 FastAPI 查询实际主库，检索“四君子汤”返回真实实体 ID。
2. Neo4j 样例与主库 `build_id` 一致，证据 ID 可回查。6 节点、5 关系的样例不代表完整图谱。
3. 模型真实调用才算连接通过；模拟测试只验证客户端协议。
4. 主库故障返回 503；图或模型不可用不阻塞普通检索。
5. 凭据不进入前端、Git 或报告；当前服务仅监听本机。
6. 应用使用只读事务；独立业务只读账号在后续 API 阶段实施。

最终交付仍须同时满足 Vastbase、Neo4j、真实 AI 和十万条以上数据，本阶段通过不代表最终指标全部完成。
