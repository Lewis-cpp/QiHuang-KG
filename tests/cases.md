## M2 资料检索页面（spec §5.11）

在浏览器中执行；2026-10-11 的结果见 [docs/acceptance/m2-browser.json](../docs/acceptance/m2-browser.json)。

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| M2-01 | 打开 `/` | 显示简介和三个示例检索，不发起检索请求 |
| M2-02 | 检索"四君子汤" | URL 带 `q`；首条为四君子汤，显示"名称命中" |
| M2-03 | 打开四君子汤 | 标题为"四君子汤 · 岐黄知图"；组成表 4 行，含位置、剂量原文、君臣佐使 |
| M2-04 | 组成中点甘草，再点"收录该药的方剂"中的其他方剂 | 依次进入中药详情和该方剂详情 |
| M2-05 | 打开该方剂一条组成证据，再点证据对象的起点 | 证据页显示"起点 → 包含 → 终点"；链接回到方剂 |
| M2-06 | 连续点浏览器后退 | 依次回到证据、方剂、甘草 |
| M2-07 | 打开猪苓汤 | 泽泻行显示"⚠ 来源记载不一致"和脚注；两条证据原值不同 |
| M2-08 | 打开甘草（饮片）`tcm-mkg:herbal_piece:CHP01118` | "含该饮片的中成药"共 2,278 条，可以翻页 |
| M2-09 | 打开 ICD-11 编码 `tcm-mkg:icd11_code:1F68.1` | 属性只有编码 |
| M2-10 | 打开中成药 `tcm-mkg:patent_medicine:CPM00001` | 给药途径显示"口服（Oral）" |
| M2-11 | 打开 `/datasets` 和 `/stats` | 两个来源卡片；统计显示"实体 20,374 + 业务关系 179,502 = 199,876"和运行状态 |
| M2-12 | 在开发服务和 `vite preview` 中刷新检索、实体、证据、来源、统计页面 | 都回到原页面 |
| M2-13 | 打开不存在的实体 ID、证据 ID、格式不合法的 ID、不存在的路径 | 前三个显示"未找到"，最后一个显示"页面不存在" |
| M2-14 | 检索一个不存在的词 | 显示空结果说明 |
| M2-15 | 停止后端，打开各页面；恢复后点"重试" | 显示"无法连接服务"和"重试"；重试后正常显示 |
| M2-16 | 停止数据库，打开详情页和统计页 | 显示后端返回的 `message`；统计页的运行状态仍可见 |
| M2-17 | 把 `sessionStorage` 中的 `qihuang.build_id` 改成另一个合法值，再检索 | 顶部出现"数据已更新"横幅；点"刷新"后恢复 |
| M2-18 | 390 px 宽度下打开检索、详情、统计、来源 | 页面没有横向滚动条 |
| M2-19 | 首次打开 `/stats`，让 `/datasets` 晚于 `/stats` 返回且带另一个批次；再交换响应顺序 | 两种顺序都出现"数据已更新"横幅；已保存的批次不被覆盖；异批次分区显示刷新提示，不渲染返回的数据 |
| M2-20 | 不填关键词，类型选"中药"，再切回"全部类型" | URL 去掉 `type`，回到初始状态，不再显示中药目录 |
| M2-21 | 打开 `/?q=四君子汤&page=2` 和 `/?type=herb&page=99` | 分别回到第 1 页和最后一页（第 19 页），显示结果 |
